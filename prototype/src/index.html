    Client microsite · Forms

    Send the team scoping survey to a Google Sheet

    The survey is part of the microsite, so participants never see a Google Form or a script warning. One Sheet can collect every client: each row names the client and the proposal.

    1. Create or open the Google Sheet that should collect replies, then choose Extensions → Apps Script.
    2. Press Copy script below and paste it over everything in Code.gs. Save.
    3. Choose Deploy → New deployment, type Web app. Set Execute as: Me and Who has access: Anyone, then deploy and allow access when Google asks.
    4. Copy the Web app URL (it ends in /exec) and paste it into Google Sheet link under Client microsite.
    5. Export the microsite, publish it, and send one test from the published page. A Pre-training survey tab appears in the Sheet with the row.

    A browser cannot read the Sheet’s reply from inside the shared proposal, so the microsite shows “Thank you” once the request has left, and always gives the participant a copy to email or WhatsApp. The link is visible in the page’s code, so treat the Sheet as an inbox and keep anything sensitive elsewhere.
