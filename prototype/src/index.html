    Put the client microsite on Google Sites

    What to export

    Proposal deck layout

    A full page in Google Sites No resizing

    1. Click Copy embed code below.
    2. In Google Sites, open the Pages tab, click + at the bottom and choose Full page embed. Name the page.
    3. Click Add embed, choose Embed code, paste, then Next and Insert. Publish the site.

    It fills the page and scales to each visitor's screen, so there is nothing to stretch. Phones get shorter tab names and the readable page version of the deck automatically.

    Inside an existing page

    1. Choose Insert → Embed → Embed code, paste and click Insert.
    2. Google Sites decides the size of the embed box, and nothing inside the code can change it. Drag the box's corner once, to the width you want.

    Whatever size the box ends up, the tab bar stays on top and each tab scrolls inside it, so there is never a second scroll bar. Give it at least 700 pixels of height for the calculator and forms.

    Google Sites keeps the copy you paste. After any change to this proposal, or to this builder, copy the code again and replace the old embed: select it in Google Sites, choose Edit, paste the new code and publish the site.

    Client microsite · Forms

    Send the team scoping survey to a Google Sheet

    The survey is part of the microsite, so participants never see a Google Form or a script warning. One Sheet can collect every client: each row names the client and the proposal.

    1. Create or open the Google Sheet that should collect replies, then choose Extensions → Apps Script.
    2. Press Copy script below and paste it over everything in Code.gs. Save.
    3. Choose Deploy → New deployment, type Web app. Set Execute as: Me and Who has access: Anyone, then deploy and allow access when Google asks.
    4. Copy the Web app URL (it ends in /exec) and paste it into Google Sheet link under Client microsite.
    5. Export the microsite, publish it, and send one test from the published page. A Pre-training survey tab appears in the Sheet with the row.

    A browser cannot read the Sheet’s reply from inside Google Sites, so the microsite shows “Thank you” once the request has left, and always gives the participant a copy to email or WhatsApp. The link is visible in the page’s code, so treat the Sheet as an inbox and keep anything sensitive elsewhere.
